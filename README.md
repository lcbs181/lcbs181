## 🎧 Featured project

<div align="center">

### [Grooveo](https://github.com/lcbs181/grooveo)
*An on-device SoundCloud + YouTube Music client — no backend, no account, no login screen.*

[![Repo](https://img.shields.io/badge/source-grooveo-A78BFA?style=for-the-badge&logo=github&logoColor=white)](https://github.com/lcbs181/grooveo)
[![Latest release](https://img.shields.io/github/v/release/lcbs181/grooveo?style=for-the-badge&color=6D28D9&label=latest&logo=android&logoColor=white)](https://github.com/lcbs181/grooveo/releases/latest)
[![License](https://img.shields.io/github/license/lcbs181/grooveo?style=for-the-badge&color=4C1D95)](https://github.com/lcbs181/grooveo/blob/master/LICENSE)
[![Downloads](https://img.shields.io/github/downloads/lcbs181/grooveo/total?style=for-the-badge&color=7C3AED&label=downloads)](https://github.com/lcbs181/grooveo/releases)

| | |
|---|---|
| 🎵 **Search** | SoundCloud + YouTube Music, per-source or combined |
| 📡 **Streaming** | Resolved entirely on-device — no proxy, no server |
| ⬇️ **Downloads** | Offline playback with a data-saver mode |
| 🎛️ **Player** | Waveform seek bar, 4-band EQ, sleep timer, shuffle/repeat |
| 🏠 **Home** | On-device "Für dich" feed from your own listening history |
| 📱 **Widget** | Jetpack Glance home-screen playback controls |
